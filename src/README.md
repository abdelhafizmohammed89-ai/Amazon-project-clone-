     🛒 Amazon E-Commerce Website Clone

A feature-rich e-commerce web application built with HTML, CSS, and JavaScript, inspired by the shopping experience of Amazon. This project demonstrates how core e-commerce features work together, from browsing products and managing a shopping cart to completing checkout and tracking orders.

The goal was to build a practical shopping experience while strengthening my understanding of modern JavaScript, DOM manipulation, object-oriented programming, asynchronous operations, and modular application design.

Note: This is an educational project inspired by Amazon. It is not an official Amazon product or affiliated with Amazon.

✨ Features what i include in the system.

🛍️ Product Browsing

Display products dynamically from product data.

Organize product information, including images, prices, ratings, and descriptions.

Search for products using keywords.

Support different product types through reusable JavaScript classes.

🛒 Shopping Cart

Add products to the cart.

Increase or decrease product quantities.

Remove products from the cart.

Select delivery options for individual items.

Calculate cart quantities and prices dynamically.

Save cart data using localStorage so it persists across page refreshes.

💳 Checkout & Order Summary

Display selected products and their quantities.

Calculate item totals, shipping costs, and order totals.

Update the order summary when cart items or delivery options change.

Organize checkout functionality into reusable JavaScript modules.

📦 Orders & Tracking

Save completed orders and display order history.

Buy products again from previous orders.

Track individual products through an order's delivery progress.

Calculate delivery progress using date and time operations.

🧪 Testing & Code Quality

Write unit tests using Jasmine.

Test important cart and order-summary functionality.

Use ES modules to organize code across multiple files.

Apply object-oriented programming with classes, inheritance, and encapsulation.
